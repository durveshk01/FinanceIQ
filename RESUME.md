## Interview Explanation Version

FinanceIQ is a full-stack fintech portfolio project that lets a user upload a bank statement and receive a structured financial report. The frontend is a premium responsive Next.js interface with demo mode, upload validation states, animated analysis progress, dashboard tabs, Recharts visualizations, and a floating AI coach. The backend uses Next.js API routes to validate files, parse transactions, categorize spending, build an insight report, power chat responses, and export reports in CSV, XLSX, PDF, and JSON.

The engineering focus was to make the project feel realistic without overclaiming production maturity. I added schema validation, file validation, rate limiting, security headers, prompt-injection-aware AI prompts, and clear privacy messaging. I also documented limitations such as in-memory rate limiting and the need for malware scanning and observability before accepting real user bank statements at scale.
